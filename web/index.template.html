Engine

The seven data structures are hand-written C++ classes in their own modules. The application layer uses them directly, and everything is compiled for this page. Running as: starting.

C++ application layer

  • User, Player, Admin
    Abstract base with inheritance and a virtual describe()
  • Game, Team, Match
    Encapsulated state with validation
  • Tournament
    Abstract; Knockout, RoundRobin and Swiss override the format rules
  • Leaderboard, ArenaSystem
    Ranking through the sort module; controller, search and file handling
  • ArenaError family
    Duplicate, NotFound, InvalidOperation and Permission errors
